사용자 요청

1. 관문 입장시 상단에 버튼형 튜토리얼 띄우기(도시화면에 있는 그거)

- 관문의 특수성에 대한 대략적인 설명
- 국경 관세와 통행증
- 통관 게시판

2. 도시, 관문, 마을 등의 화면에서 시설버튼들이 있는 구역의 거점명 위쪽 공간에 통행증 표시 UI 추가. 색은 국가색을 찾아 사용합니다. (마레시아 빨강, 라베르 초록, 브라벤 파랑)

- 처음 통행증 얻었을 때 튜토리얼 진행

작업 전 응답

관문 전용 안내 버튼을 도시의 교역 안내·소식 안내와 같은 형식으로 추가하고, 통행증은 거점명 바로 위에 국가색 띠 형태로 표시하겠습니다. 최초 통행증 튜토리얼은 관세 납부 직후 다른 진입 이벤트와 겹치지 않도록 기존 화면 우선순위 큐에 연결하겠습니다. 먼저 현재 거점 헤더 구조와 튜토리얼 진행 조건을 확인한 뒤 0.00.314로 두 폴더에 반영하겠습니다.
