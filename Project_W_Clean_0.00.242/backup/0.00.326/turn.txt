사용자:
컷신으로 분류되는 메시지에만 이전 규칙을 적용합니다.

상점뷰에서 상품을 클릭했을 때 내 보유 화물의 스크롤이 움직이는 형상이 발견되었습니다.

Codex:
컷신에만 이미지 0 규칙이 적용되도록 범위를 좁히겠습니다. 상점 상품 클릭 시 양쪽 목록의 스크롤이 연결되는 원인은 거래창의 선택 후 재렌더링과 스크롤 복원 로직을 추적해 분리하겠습니다.

원인은 상품 선택 때 render()가 양쪽 상품 목록을 함께 다시 만들면서 각 목록의 독립적인 스크롤 위치를 보존하지 않는 구조입니다. 재렌더링 전후에 플레이어와 상인 목록의 위치를 각각 저장·복원하고, 새 점포를 열 때만 두 위치를 초기화하도록 고치겠습니다.
