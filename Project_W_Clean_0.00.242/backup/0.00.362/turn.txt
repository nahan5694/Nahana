[사용자 요청]
1. 거래창에서 화폐를 꾸욱 누르면 갯수 입력창 띄우기. 입력한 갯수에 맞춰 몇 가치를 올리는건지, 해당 갯수를 올리면 합계 몇 가치가 되는지 보여주기.
2. 세이브 슬롯 3개. 여행 재개/새로운 여정에서 슬롯 선택, 진행 슬롯 초기화 확인, 현재 데이터 슬롯1 안전 이관, 이름·행상인 레벨·동행 레벨 표기.
3. 행상인의 길 상품지식에서 선물항목 제거.
4. 새 게임 이름 결정 전에 식품상인/직물상인/잡화상인 오리진 선택. 전문 지식 2, 숙련 지식 1로 시작.

[백업 전 Codex 응답]
현재 저장 구조와 거래 입력 이벤트, 상품지식 분류, 신규 게임 초기화 순서를 점검했습니다. 세이브는 네 저장 영역을 슬롯별로 분리하며 기존 데이터를 슬롯 1에 복사·검증한 뒤에만 기존 키를 정리하는 방식으로 보존합니다. 이관 실패 시 기존 키를 유지하고 슬롯 기능을 비활성화하도록 설계했습니다. 구현 범위를 확정하고 거래 수량 입력, 슬롯 선택, 오리진, 상품지식 제외를 반영합니다.
