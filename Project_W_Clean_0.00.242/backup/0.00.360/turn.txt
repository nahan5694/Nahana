사용자:
T_C_020  대화카드 사용시 기분이 3 감소하는것을 발견했습니다. 이는 시트와 맞지 않습니다. 비슷한 증상이 다른 몇몇 카드에서도 일어나는 것 같습니다. 검토해보세요.

Codex:
`T_C_020`의 시트 기분 변화값과 카드 실행 경로를 대조하고, 대화카드 공통 처리나 상태 효과에서 추가 감소가 중복 적용되는지 확인하겠습니다. 같은 방식으로 다른 카드도 전체 대조해 공통 원인인지 개별 데이터 문제인지 구분하겠습니다.

시트의 `T_C_020`은 기분 값이 비어 있어 카드 자체 효과는 0이어야 합니다. 현재 실행 코드도 빈 값을 0으로 읽지만, 카드 적용 직후 상태이상 정산 함수가 함께 호출되므로 그 과정에서 별도의 `-3`이 카드 효과처럼 합산 표시되는 가능성을 확인하고 있습니다.

원인을 확인했습니다. 현재 게시 시트에서 `T_C_020`의 기분 효과는 `+5`가 맞습니다. 문제는 선물로 최대 기분이 100을 넘은 상태에서도 대화카드 적용 코드가 기분을 무조건 `0~100`으로 다시 제한한다는 점입니다. 예를 들어 현재 기분이 103이면 `+5`를 적용하는 과정에서 100으로 잘려 결과가 `-3`으로 기록됩니다. 기분 효과가 0인 카드도 100 초과 상태에서는 같은 문제가 생길 수 있습니다.
