백업 전 Codex 응답:
메인 메뉴에서 강제로 표시하던 CSS 버튼을 제거하고 Asset_Main_05, Asset_Main_06 이미지를 다시 그대로 사용하겠습니다. 새 여정 선택창의 하늘색 구성은 유지하되 메인 버튼에는 색 보정을 적용하지 않고, 업적은 우측 상단에 별도의 작은 이미지 버튼으로 배치하겠습니다.
