사용자 요청

수입품 관련 수정사항을 반영합니다.

- 단, 수입품은 열화로 인해 어느정도 효과적이지 못한 상품임이 이미 반영되어있습니다. 그렇기에 플레이어가 수입품을 판매시 얻는 거리 보정을 생산품보다 1.75배정도 높게 가하는 것이 좋을 것 같습니다.

작업 전 응답

앞서 정리한 구입처 기준 규칙을 적용하겠습니다. 생산품은 그대로 두고, 수입품·고정물류·재판매품은 구입 거점에서 14칸 이내 판매 시 원산지 거리 보너스를 막고 15~29칸에서 점진적으로 해제하겠습니다. 실제 수입품은 열화 부담을 반영해 해제된 거리 보정을 생산품의 1.75배로 계산하고, 열화가 절반인 고정물류에는 1.75배를 적용하지 않겠습니다. 먼저 기존 거래 묶음에 구입처와 유통 유형이 빠짐없이 남는지 확인한 뒤 0.00.316으로 반영합니다.

구입 거점과 실제 유통 유형은 이미 수량 묶음별로 저장되고 있어 저장 구조를 늘릴 필요가 없습니다. 보너스 해제에는 실제 주행거리가 아니라 구입처와 판매처 사이의 최단거리를 사용해 우회 주행 악용을 막고, 여러 곳에서 산 물건이 합쳐진 경우 수량 비율대로 계산하겠습니다.
